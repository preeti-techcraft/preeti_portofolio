# Personal Developer Portfolio

Welcome to my personal developer portfolio! This project is a modern, responsive, and visually dynamic web portfolio built to showcase my education, technical skills, web development projects, and achievements.

## 🚀 Features

- **Responsive Design**: Flawlessly adapts to desktop, tablet, and mobile screens.
- **Dark Theme Aesthetics**: Premium dark background accompanied by striking neon gradients and smooth hover interactions.
- **Categorized View**:
  - **Hero Section**: A dynamic introduction and direct links to my social profiles.
  - **Education**: Detailed timeline of academic qualifications (M.C.A., BCA, Secondary Education).
  - **Technical Skills**: Categorized technical stack covering Programming Languages, Web Development, Databases, and Core Concepts.
  - **Projects**: Professional display of my latest coding projects and the technologies powering them.
  - **Achievements**: Major professional accolades and competition rankings.
  - **Contact Form**: A clean, fully responsive layout engineered for immediate connections.

## 🛠️ Technology Stack

- **HTML5**: For semantic page structure and accessibility.
- **CSS3 / Vanilla CSS**: Built exclusively with raw CSS featuring custom flexbox/grid layouts, CSS root variables, and keyframe animations.
- **FontAwesome**: Utilized for highly scalable vector icons.
- **Google Fonts**: Clean typography using the 'Outfit' font family.

## 💻 How to Run Locally

Because this portfolio relies solely on raw HTML and CSS without the overhead of heavy frameworks, running it locally is incredibly fast and simple:

1. Clone or download this project folder to your machine.
2. Navigate to the project directory.
3. Simply double-click on `portoflio.html` to open it locally in your default web browser.

*(Optional)* You can also open the project in **VS Code** and run the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension if you wish to experiment with the code and see changes in real time.
